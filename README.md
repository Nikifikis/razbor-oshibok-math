# Разбор ошибок — серверная версия

Приложение хранит классы, учеников, назначения и прогресс в SQLite. Учитель входит через отдельную защищённую страницу, ученики — по коду класса, имени и PIN.

## Развёртывание

1. Создать `.env` из `.env.example` и задать хеш пароля учителя.
2. Запустить `docker compose up -d --build`.
3. Направить Nginx на `127.0.0.1:8020` и включить HTTPS.

База находится в `data/razbor.sqlite`; каталог `data` нужно включить в резервное копирование.
