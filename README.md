# Разбор — работа над ошибками

Интерактивный прототип для самостоятельной работы над ошибками по математике в 7–8 классах.

## Что уже работает

- выбор класса, темы и уровня 2.0/3.0;
- два сценария: известные ошибки или диагностика с нуля;
- темы «Числовые выражения», «Математический язык и модель», «Линейные уравнения»;
- новые значения и формулировки вместо копирования контрольных вариантов;
- пошаговые подсказки, проверка ответа и карта навыков;
- локальное сохранение прогресса в браузере.

Рабочая версия: https://razbor-oshibok-math.bessievancampt216663.chatgpt.site

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.
