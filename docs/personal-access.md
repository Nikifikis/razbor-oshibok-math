# Персональная работа над ошибками

## Работа учителя

1. Войти в `/teacher.html` на серверном адресе проекта.
2. Создать класс и добавить ученика. Скопировать его личный код, показанный один раз.
3. В назначении выбрать конкретного ученика, тему, уровень и нужные навыки. Весь класс можно выбрать отдельно, осознанно.
4. Указать число самостоятельных примеров и открыть работу. Число не может быть меньше количества навыков; примеры равномерно распределяются между ними. Повторять один лёгкий навык вместо остальных нельзя.
5. Смотреть ответы по шагам, ошибки и подсказки кнопкой «Посмотреть шаги».
6. Закрыть доступ к назначению, когда работа больше не нужна. Перевыпуск личного кода отключает старый код и старые сеансы, сохраняя назначения и результаты.

Ребёнок вводит один личный код и видит только свои активные назначения. Каталога тем, выбора класса и свободного переключения в 3.0 в ученическом режиме нет.

## Проверка доступа и ответов

Каждый запрос задания, ответа, подсказки и перехода проверяется на сервере: ученик, активное назначение, тема, уровень, выбранный навык и текущий шаг. Ответы не принимаются в виде переданного клиентом флага `correct`. Идентификаторы вариантов непрозрачные; проверка выполняется по сохранённому заданию. Повторный ответ и параллельные запросы не дают повторного начисления результата.

Сначала проходят промежуточные действия. Самостоятельная проверка доступна только после разбора назначенного навыка. Для неё создаётся другой пример, без образца, правила и подсказок. Правильные промежуточные действия не засчитываются отдельными завершёнными примерами.

Старые назначения без списка навыков не открываются ученикам. Имена и предыдущие результаты в базе сохраняются; учитель выдаёт личные коды и новые точные назначения.

## Учебные материалы

Тренировка задаётся навыками, а не номерами вариантов подтверждения. В `training.js` используются новые конструкции: исследование положительного знаменателя, восстановление пропущенной части равенства, три дроби вместо пары, сумма кубов, дробное уравнение с двумя допустимыми корнями, поиск ошибочной модели. Ограничения проверяются по исходным выражениям. Самостоятельный пример и образец не совпадают с текущим разбором.

Сервер не отдаёт генератор и ключи ответов как публичные файлы. GitHub Pages публикует закрытую страницу входа: без работающего сервера она не открывает тренировку. Это не позволяет удалённо отозвать содержимое ранее открытых страниц, сохранённых файлов или публичной истории Git; переписывание истории и смена видимости репозитория отдельно не выполнялись.

## Проверки

- `npm run check`: синтаксис и 1320 сгенерированных вариантов, включая преобразования и допустимость корней.
- `npm run test:access`: личный код, чужой ученик, неназначенный навык, неназначенный уровень, запрет клиентского начисления результатов, обязательный разбор, конкурентные ответы, отзыв доступа и журнал учителя.

Для реальных детей необходим HTTPS и сервер Node.js с постоянной базой. GitHub Pages не запускает Node.js и не хранит такие назначения.
